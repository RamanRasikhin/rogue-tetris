Windows launcher and packaging fix.

Windows x64: download RogueTetris-Windows-x64.zip, extract the entire archive and double-click start.bat. Java 17 is included; no installation is required. Launch errors remain visible and are saved to logs/launch.log.

The standalone rogue-tetris-1.0.1.jar requires an installed Java 17+.
The automatically generated Source code archives are for developers: their start.bat builds the game on first run and needs a JDK 17+ plus internet access.

The game rules are unchanged. Public-edition buttons/blocks/markers are rendered from code, sounds are synthesized and the font is Rajdhani (OFL). Existing CC BY backgrounds and Shikashi icons are credited in CREDITS.md. No new AI-generated images were created for this edition; the original background creator discloses Midjourney.
